# Supabase is not used

Motion uses **Neon PostgreSQL** and **server-owned administrator sessions**. Customers never create accounts. There is no Supabase Auth, Data API, or Storage client in this codebase.

This file remains so old links do not 404.

See `ENVIRONMENT.md` for Neon connection variables and administrator configuration, `DEPLOYMENT.md` for Render, and `SCHEMA.md` for guest contacts and sessions.
